# 📦 Как выпустить Свиноклауд на GitHub

Пошаговая инструкция: от создания репозитория до работающей кнопки обновления.
Всё делается один раз, дальше — только по шагу 4 (новые выпуски).

---

## Шаг 0. Что понадобится

- Аккаунт на [github.com](https://github.com).
- Git (уже установлен — команды `git` работают).
- Твой ник на GitHub. В этой инструкции он называется **`ТВОЙ_НИК`** — замени его на свой везде.

> ⚠️ **Важно про имя.** Уже настроено под репозиторий `Rabedun/SvinoCloud`
> (см. `GITHUB_REPO` в `updater.py`). Если репозиторий переименован или живёт
> под другим ником — поправь `GITHUB_REPO` в `updater.py` на `ТВОЙ_НИК/НАЗВАНИЕ`,
> иначе плеер не найдёт обновления (ошибка 403/404).

---

## Шаг 1. Создать репозиторий на GitHub

1. Открой https://github.com/new
2. **Repository name:** `SvyazCloud`
3. Выбери **Public** (обязательно! для приватного проверка обновлений без токена не работает).
4. **Не** ставь галочки «Add a README / .gitignore / license» — они вызовут конфликт при загрузке.
5. Нажми **Create repository**.

---

## Шаг 2. Загрузить код на GitHub

В PowerShell в папке плеера (`D:\СвязьКлауд`) выполни по очереди, подставив свой ник:

```powershell
git remote add origin https://github.com/ТВОЙ_НИК/SvyazCloud.git
git branch -M main
git push -u origin main
```

- При первом `push` откроется окно браузера — войди в GitHub и подтверди.
- Если попросит логин/пароль в консоли — вместо пароля используй **Personal Access Token**
  (см. Шаг 3), потому что GitHub больше не принимает пароль.

После этого код (включая `README.md`) появится на странице репозитория.

---

## Шаг 3. (Если просит токен вместо пароля) Personal Access Token

1. https://github.com/settings/tokens → **Generate new token (classic)**
2. Отметь галочку **`repo`** (полный доступ к репозиториям).
3. Нажми **Generate**, скопируй токен (он больше не покажется).
4. Вставь его в консоли вместо пароля. Имя пользователя — твой ник GitHub.

---

## Шаг 4. Выпустить версию (Release) — нужно для автообновления

Кнопка «Скачать и установить» работает только если на GitHub есть **Release**.

1. На странице репозитория: **Releases** → **Create a new release** (справа).
2. **Choose a tag:** введи `v1.2.0` → «Create new tag: v1.2.0 on publish».
   Тег **обязательно** начинается с `v` и совпадает с версией в `updater.py` (`APP_VERSION`).
3. **Release title:** `v1.2.0`.
4. **Description:** кратко что изменилось (этот текст плеер покажет как «Что нового»).
5. **Attach архив:** нажми «Attach binaries by dropping them here» и перетащи файл
   `Svinoklaud.zip`.
6. Нажми **Publish release**.

### Как собрать `Svinoklaud.zip`

Проще всего — двойной клик по **`Собрать релиз.cmd`** в папке плеера. Он создаст
`Svinoklaud.zip` рядом, положив туда только нужные файлы (без кэша и личных данных).

### Windows-версия без Python (exe)

Для тех, у кого не установлен Python, собери папку с exe:

1. Положи рядом со скриптом `yt-dlp.exe` (скачивается с
   https://github.com/yt-dlp/yt-dlp/releases).
2. Двойной клик по **`Собрать exe.cmd`** (нужен Python + PyInstaller:
   `pip install pyinstaller`).
3. Готовая папка — `dist\Свиноклауд\` (внутри `Свиноклауд.exe` + библиотеки).
4. Запакуй её в архив, например:
   ```powershell
   Compress-Archive -Path 'dist\Свиноклауд' -DestinationPath 'Свиноклауд-win64.zip'
   ```
5. Приложи `Свиноклауд-win64.zip` к Release так же, как `Svinoklaud.zip`
   (для пользователей это просто «скачал, распаковал, запустил»).

> ℹ️ В exe нет локального распознавания текста песен (Whisper/torch — это ~2 ГБ,
> они намеренно исключены). Всё остальное работает; если нужен Whisper —
> запускай плеер из исходников на Python.

---

## Шаг 5. Проверить, что обновление работает

1. Открой плеер → шестерёнка ⚙️ → **🔄 Проверить обновления**.
2. Должно написать «Плеер актуален (установлена 1.2.0)», а когда выпустишь
   следующую версию (например `v1.3.0` — не забудь поднять `APP_VERSION` в
   `updater.py`) — появится кнопка **⬇ Скачать и установить**.

---

## 🔁 При каждом новом выпуске

1. Подними версию в `updater.py`: `APP_VERSION = "1.3.0"`.
2. Сохрани изменения (двойной клик **`Сделать коммит.cmd`**).
3. Отправь на GitHub:
   ```powershell
   git push
   ```
4. Собери архив (**`Собрать релиз.cmd`**) и создай **Release** с тегом `v1.3.0`
   + приложи архив (Шаг 4).

---

## 🐛 Частые ошибки

| Ошибка | Причина и решение |
|--------|-------------------|
| Проверка обновлений → **403 / 404** | Репозитория нет, он **приватный**, или имя в `updater.py` (`GITHUB_REPO`) не совпадает с реальным. Сделай репозиторий **Public** и проверь имя. |
| Кнопка «Скачать» говорит «нет файла в выпуске» | К релизу не приложен zip. Добавь архив (Шаг 4). |
| `git push` просит пароль и ругается | Нужен Personal Access Token (Шаг 3), не пароль. |
| После обновления пропал плейлист | Не должно быть: `playlist.json` защищён (`PROTECTED_FILES`). Если пропал — значит запускался не тот плеер. |
